# 更新日志

## 1.4.2

- 首页瀑布流改为 **JS 弹性列**布局：卡片按响应式列数分配到独立弹性列，**首行完全顶对齐**（修复 CSS 多列在高度悬殊时的顶对齐错位）；
- 懒加载加固：修复滚动跳过导致的漏加载，改为全量检查；`throttle` 以 `Date.now()` 重写并监听加 `passive`；
- 瀑布流空数据不再创建空列，重建后立即触发一次懒加载检查；
- README 全面重写为当前功能状态。

## 1.4.1

- 底部固定栏改为苹果 Newsroom 式**居中悬浮圆角胶囊**（沿用原深色配色）；
- 头像圆心与胶囊左弧圆心重合，全屏/「关于」按钮胶囊化并与右弧圆心对齐；
- 全屏按钮 hover 不再闪现旧圆角矩形（修复优先级）;
- 移除底栏「关于」文字按钮（点击左侧站点信息仍可打开关于面板）；
- 胶囊内元素留白加大，长度随内容自适应。

## 1.4.0

- 首页改为瀑布流（多列 + 照片自然高度 + 原生懒加载）；
- 照片与网页边缘统一 14px 边距（与照片间距一致），照片加 10px 普通圆角；
- 底部固定栏（关于/站点信息）高度压缩约 1/3；
- 修复 `#main` 为 flex 导致的瀑布流列宽/边距不匀。

## 1.3.2

- 灯箱切图：宽幅照片打开/切换时直接按预留侧栏宽度渲染，不再闪一下原尺寸再收缩；
- 镜头展示：统一使用 EXIF 读取到的镜头描述（含手机），读不到则不显示，不再推断；
- 修复 EXIF 读取遗漏：兼容部分环境下镜头标签被标为 `UndefinedTag:0xA434` 的情况，忽略 `'----'`/`Unknown` 占位符。

## 1.3.1

- 后台上传：预览区改为整行自适应网格（不再撑乱两列表单），已选文件支持追加且去重，上传按钮与「选择图片」标签靠拢；
- 灯箱 EXIF：新增「镜头」展示——有真实镜头名显示真实名；手机照无镜头名时按等效焦距推断（主摄/超广角/长焦）；非手机且无准确镜头名则不显示；
- EXIF 读取：兼容部分环境下镜头标签被标为 `UndefinedTag:0xA434` 的情况，忽略 `'----'`/`Unknown` 占位符。

## 1.3.0

- 灯箱 EXIF 侧栏改为在灯箱打开时才轮询刷新，关闭即停止（省去后台空转）；
- EXIF 面板新增「镜头 / 闪光」展示，焦距统一优先显示 35mm 等效焦距（静态与弹窗一致）。

## 1.2.0

- 灯箱：宽幅/全景照片会收缩展示宽度，为 EXIF 停靠栏腾出空间，避免遮挡照片；
- 后台：上传时展示所选文件的大图预览，并支持逐张填写图片标题与描述（不再只能填图集标题）；
- 后台：重建缩略图/全图不再“卡死”——外部转码工具（magick/heif-convert）带超时、单次请求限时推进、失败计数并提示；
- 后台进度文件改为原子写入，避免多次操作写入不一致。

## 1.1.0

- 上传失败给出明确提示（大图超限 / 部分上传 / 临时目录缺失等）；
- 焦距改为显示 35mm 等效焦距（优先 EXIF，缺省按传感器尺寸/机型补算）；
- 灯箱「地点 / 地址」为空时自动隐藏；
- 移除灯箱失效的旧切换处理器与标记、未引用资源，`detectTools` 缓存、图集列表合并查询。

- 后台：WebP 质量滑块 + 恢复默认、站点信息、联系方式可视化选图标、图集维护；
