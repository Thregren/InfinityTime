# 更新日志

## 1.7.3

### 修复：灯箱切图顺序
- **根因**：无限瀑布流把卡片按列重排（`.wf-col`），导致 poptrox「上一张/下一张」按**列序**（先一列往下、再下一列）切图，与首页从左到右的阅读顺序不一致。
- **修复**：给每张卡片记录**源码顺序** `data-pp-order`（首个 build 时按 PHP 输出顺序、翻页后继续追加；resize 不覆盖），灯箱改用该顺序切图（按源码顺序从当前图切到相邻的上一张/下一张），不再按瀑布流列序乱跳。无限瀑布流新加载的卡片也计入顺序。

## 1.7.2

### 修复：无限瀑布流新图片未绑定灯箱
- **根因**：poptrox 只在初始化时给锚点绑定点击（并移除其 `href`），无限瀑布流 `fetch` 到第 2 页后 `appendChild` 的新卡片从未被绑定 → 点击直接跳 `.webp` 原图。
- **修复**：翻页后安全重绑一次。关键点：poptrox 只绑定「还有 `href`」的锚点，而早已绑定的卡片 `href` 已被移除，重绑前先从 `data-images[0]` **补回 `href`**，否则重绑会跳过旧卡片导致「所有灯箱打不开」（此前的回退正是咬在这一步）。

### 全景全屏交互
- 全景浏览器**全屏时不再响应「点击就退出/关闭」**；非全屏时点击遮罩仍可正常关闭灯箱。
- 全屏下「进入/退出全屏」按钮与 Pannellum 控件、热区仍可正常点击。

### 健壮性
- `main.js` 所有 `JSON.parse(data-*)` 改用 `ppParseArr()`（非法/缺失回退空数组），不再因单个脏 `data-*` 导致全站 blur-up/多图切换静默失效。
- 灯箱/全景 120ms 轮询回调整体加 `try/catch`，避免单次异常每 120ms 刷控制台。
- 全景销毁时解绑 `document` 级捕获监听（`ppUnbindPanoGuard`），灯箱关闭后不再常驻空转。

## 1.7.1

### 安全加固（重点）
- **存储型 XSS 防护**：前台图片卡的 `data-images / data-exif / data-titles / data-descs / data-addresses` 等 JSON 改用 `JSON_HEX_APOS|JSON_HEX_QUOT|JSON_HEX_AMP|JSON_HEX_TAG` 安全标志嵌入 HTML 属性，避免图片标题/描述/文件名含 `' " & < >` 时破坏属性或注入脚本。
- 卡片上直接输出的**设备/地点**、以及灯箱**光圈/焦距**等由 EXIF/字段提供的文本全部 `htmlspecialchars` 转义，防止恶意 EXIF 元数据注入。
- **后台 CSRF 防护**：`panel.php` 的所有 POST 操作（上传/编辑/删除/设置/维护）增加**同源校验**（校验 Referer 主机），拦截跨站伪造请求。
- 移除 `comments.php` 中遗留的、使用了已废弃 `/e` 正则修饰符的死代码函数 `getTopDomainhuo`（PHP 7+ 会报错）。

### 代码清理
- 删除主题里**未被引用的重复文件**：主题根目录 `main.css`、`main.js`（实际只加载 `assets/` 下的）。
- 删除插件里**未被引用的重复类文件**：插件根目录 `MediaProcessor.php`、`ImageRepository.php`（实际只用命名空间 `Lib/` 下的，避免潜在的“重复声明类”隐患）。

- EXIF 面板新增「镜头 / 闪光」展示，焦距统一优先显示 35mm 等效焦距（静态与弹窗一致）。

## 1.2.0

- 灯箱：宽幅/全景照片会收缩展示宽度，为 EXIF 停靠栏腾出空间，避免遮挡照片；
- 后台：上传时展示所选文件的大图预览，并支持逐张填写图片标题与描述（不再只能填图集标题）；
- 后台：重建缩略图/全图不再“卡死”——外部转码工具（magick/heif-convert）带超时、单次请求限时推进、失败计数并提示；
- 后台进度文件改为原子写入，避免多次操作写入不一致。

## 1.1.0

- 上传失败给出明确提示（大图超限 / 部分上传 / 临时目录缺失等）；
- 焦距改为显示 35mm 等效焦距（优先 EXIF，缺省按传感器尺寸/机型补算）；
- 灯箱「地点 / 地址」为空时自动隐藏；
- 移除灯箱失效的旧切换处理器与标记、未引用资源，`detectTools` 缓存、图集列表合并查询。

## 1.0.0

- 主题更名「无限时光 / InfinityTime」，配套插件同步更名；
- 纯图片分享：上传自动转 WebP + 缩略图、EXIF 侧栏、每图标题/描述/地址；
- 后台：WebP 质量滑块 + 恢复默认、站点信息、联系方式可视化选图标、图集维护；
- 去除对 Typecho 原生文件的改动，安装主题 + 插件即可使用。
