# 公开图库查询与链接

## 筛选语义

首页表单使用 GET，禁用 JavaScript 后仍能搜索、筛选、浏览照片和继续分页。

- q：相册或照片的标题、描述包含完整关键词即可命中；不区分大小写，不做分词。相册标题或描述命中时，其照片仍须满足下列筛选条件。
- kind：all（全部）或 pano（全景）。有尺寸时按宽高比 1.98–2.02 判断；旧照片没有尺寸时沿用原全景标记。
- month：YYYY-MM。使用该张照片有效 EXIF 拍摄日期的年月；没有有效拍摄日期时，仓库照片使用上传时间（UTC），字段历史照片使用相册创建时间（UTC）。日期全缺失时归为“日期未知”。同一图集跨月份时会分到多个月份组。
- tag：完整标签名称精确匹配。合并插件 fields.tags（英文逗号、中文逗号或换行分隔）和 Typecho 原生标签并去重。原生标签归档也使用此模型。
- category：Typecho 原生分类的 slug。原生分类归档保留该约束，后续筛选及分页不会丢失分类。
- 多个条件取交集；全景、月份及照片关键词必须命中同一照片，不能由相册中不同照片分别满足。

月份导航展示当前页的月份；月份输入框可以直接查询全库任意月份。图集按 CID 降序遍历，每页中的照片再按实际月份降序分组；不声称这是跨所有分页的全局拍摄时间排序。

## 公开接口及隐私

站点根地址加 ?infinitytime_api=gallery 返回 JSON，与首页共享同一读取和筛选逻辑。支持上述筛选参数以及 album、photo、cursor、limit。站点部署在子目录时沿用实际 siteUrl，不依赖特定伪静态规则。

仅返回已经发布、到达发布时间、没有密码且类型为 post 的相册。不使用当前登录人的额外读取权限。所有照片通过显式公开字段白名单输出；不查询原图、GPS、哈希列，不将原始数据库行直接返回。EXIF 只保留相机、镜头、ISO、光圈、快门、焦距、闪光和拍摄日期；历史记录的 GPS、文件名、厂商备注等同样会被移除。媒体地址拒绝脚本/data URL、协议相对地址、original 目录与路径穿越。地址说明是用户填写并主动展示的公开文字，不从坐标推算。

响应含 albums、next_cursor、next_url、scan_limited。API 的 next_url 会保留接口参数和全部筛选条件。查询故障返回 503 和不含数据库错误详情的失败状态，不将错误当作空图库。

## 有界分页

每次只读取最多 17 个候选相册，最多扫描 16 个照片分片；每片最多返回 60 张照片，数据库多读 1 行判断是否还有后续。limit 控制有匹配照片的图集分片数，范围 1–12，默认 12。没有 COUNT 全表统计，也没有先加载整个照片仓库。

cursor 是“相册 CID.照片偏移”。大相册会先继续同一相册，再进入较早相册。达到扫描额度但尚有后续时，即使当前批次没有匹配，也返回有效游标，并显示“继续搜索更早的照片”。因此空批次不等于搜索结束。无 JavaScript 时点击下一页继续；JavaScript 加载失败可重试。

历史字段结构本身是相册级 JSON/多行文本，读取它仍需要解码该相册原有字段，但输出同样按 60 张切片，不会默默截断后续照片。查询不做表结构变更。分页反映当前排序，不建立数据库快照；浏览期间编辑、删除或重新排序照片后，建议从第一页重新浏览。稳定照片链接不受排序影响。

## 稳定链接与兼容

- 相册：?album=123
- 仓库照片：?album=123&photo=p-456，其中 456 为永久图片记录 ID。
- 仅有字段的历史照片：l- 前缀，加 SHA-256（相册 CID + 换行 + 公开照片 URL）的前 20 位十六进制。排序变化不会改变 ID；更换 URL 会改变该历史 ID。同一相册重复的相同 URL 视为同一历史照片。

直接照片链接可定位首片以外的照片。已删除、未公开或不符合当前筛选条件的照片不会回退展示其他私有内容。原生文章链接会跳转到保留相册 CID 的首页入口。

打开灯箱新增一条历史记录，切换照片更新该记录；后退关闭并恢复原筛选和滚动位置，前进重新打开照片。直接收到的照片链接关闭时只清除选中照片参数，不返回站外。相册链接可用于继续浏览完整相册。

旧图集没有同步 photo_ids 时，也直接使用仓库记录 ID。响应式变体优先按 photo_ids 关联；旧图集按精确图片 URL 关联，避免排序变化后错位，不要求管理员先重建图片。

## 验证

- php tests/gallery-discovery.php：实际 PHP 数据层、分页、隐私白名单、仓库和历史照片、完整 index.php 渲染、无 JavaScript 链接、API 子进程输出。
- node tests/gallery-navigation.cjs：深链接、后退/前进、关闭、筛选和滚动恢复，以及无效链接状态提示。
- 既有浏览器回归及 gallery-loading-browser.cjs 继续覆盖灯箱、重试和加载取消流程。
