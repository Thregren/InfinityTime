# InfinityTime · 无限时光

一款面向 [Typecho](https://typecho.org) 的**纯图片分享方案**。上传一张图，自动得到 **WebP 全图 + 缩略图**并读取 **EXIF**；前台是**无限瀑布流图片墙 + 灯箱**，灯箱侧栏展示拍摄参数；**360° 全景图在灯箱内直接可拖拽/缩放浏览**；后台可视化配置一切，后台常用编辑与上传无需整页刷新，前台搜索和分页保留原生浏览能力。

> 主题 `InfinityTime` 负责展示，插件 `InfinityTime` 负责处理。**只需安装这两部分，无需改动任何 Typecho 原生文件。**

> **v1.12.0** 重点：**主题内联 JS 外置**（`assets/js/lightbox.js`，`index.php` 从约 1100 行降到约 350 行）+ **后台图集按需 AJAX 加载**。**v1.11.0** 起已含：**响应式图片 + AVIF**（1600px 中间尺寸、两档 AVIF、`srcset`/`<picture>`）与 schema 版本化迁移。**v1.10.0** 起已含：后台面板重做（现代卡片 + 标签页、拖拽上传与进度、图片拖拽排序、图集局部刷新、维护断点续跑与并发锁）与 CSRF / HTML 清洗 / 上传前置校验。**v1.9.0** 起已含：灯箱切换体验重做、移动端底部切图按钮与抽屉常驻、桌面端标题移入 EXIF 面板、全景视窗移动端 4:3 / 桌面 16:9。**v1.8.3** 起已含：同/异比例切换动画统一、健壮性与 XSS 加固。**v1.8.1** 起已含：全景缩略图 **16:9 中央裁切**、`README` 完整开源致谢。**v1.8.0** 起已含：RGB 直方图、死代码清理。**v1.7.4** 起已含：主题色提取（3 色 + 大写色号）、CSS 列瀑布流、移动端 Safari 隐藏元素全屏。

### v1.14.0 相册工作流与浏览增强

- **先存草稿，再明确发布**：创建后保持草稿，逐张上传并显示「待上传 / 上传中 / 转换中 / 完成 / 失败」。只有点击发布才会公开；贡献者可管理自己的草稿，公开发布与已发布相册修改需要编辑者或管理员权限。
- **失败可单独重试**：同一图片操作标识与文件内容/标题描述绑定，服务器已保存的成功项不会因响应丢失而重复入库。上传与维护继续串行使用同一媒体锁，忙时保留队列并提示重试。
- **刷新后恢复**：已保存的相册与照片保留在服务器，浏览器可恢复上传清单；尚未成功的文件需重新选择。没有跨刷新保存文件字节，也不是分片续传。
- **已有相册追加**：支持向仓库管理的相册继续添加照片，不覆盖成功项。仅保存在历史文章字段、没有图片仓库记录的旧相册暂不支持直接追加，系统会在写入前阻止；旧照片仍可正常浏览。安全兼容路径是保留旧相册另建新相册，后续如需原地追加，应先备份并单独验证旧字段到仓库的导入，不能靠「重建字段」冒充导入。
- **后台分页与按需详情**：每页 20 个相册，可按标题搜索并同时看到草稿与已发布状态。列表只取本页摘要和汇总数量，展开后才分页读取照片详情。
- **严格写入校验**：所有后台变更包括维护任务均使用 POST 和有效会话令牌；管理员也必须操作真实的插件相册。持锁后的权限、去重、字段同步与文件引用检查读取主库，避免读写分离延迟。
- **公开搜索与筛选**：关键词匹配相册或照片标题/描述；全景、标签、分类、月份条件同时生效。自定义标签与 Typecho 原生标签合并展示、统一筛选，不改写已有原生分类关系。
- **拍摄月份与稳定链接**：优先使用有效 EXIF 拍摄日历月份；缺失时按照片入库时间 UTC 月份回退，旧字段照片使用相册时间。每次已加载结果按月份分组，可按月份筛选。照片链接使用稳定仓库 ID；旧字段照片使用相册 ID 与图片地址的摘要，修改旧图片地址会产生新链接。
- **有界浏览与无脚本回退**：相册按 ID 从新到旧扫描，每次最多 16 个照片块、每块最多 60 张，返回最多 12 个匹配块。稀疏筛选达到扫描上限时仍保留继续搜索链接，不误报搜索结束。无需 JavaScript 也可搜索、翻页、打开每张照片。
- **加载失败可恢复**：图片、缩略图和下一页有显式重试按钮；不支持 WebGL 时保留平面全景照片。邻图使用匹配屏幕的响应式资源，全景仍用完整分辨率；主题色和直方图尽量复用已解码图片或预览。

公开 JSON 地址为站点首页加 `?infinitytime_api=gallery`，使用与页面相同的 `q`、`kind`、`month`、`tag`、`category`、`album`、`photo` 和 `cursor` 参数。只返回已经发布、没有密码且发布时间已到的照片；输出字段白名单不包含原图地址、GPS 坐标、上传去重键或内部错误。原图文件保护仍依赖《部署与可移植性说明》中的 Web 服务器规则，请继续保留这些规则。

数据库升级仅增加可空列与唯一索引，不改写或删除原照片记录；部署前仍建议备份数据库和上传目录。多节点必须使用支持可靠 `flock` 的共享上传卷。发布包需由站点管理员按常规流程更新；本次 GitHub 发版不会自动部署线上站点。

### 图片处理（后端核心）

- **上传即转 WebP**：拦截 Typecho 上传钩子，自动生成全尺寸 WebP 与缩略图。
- **响应式 + AVIF**：额外生成 1600px 中间尺寸与两档 AVIF；前台灯箱用 `srcset` / `<picture>` 按屏幕与格式选择，手机与支持 AVIF 的浏览器更省流量。
- **上传可靠**：后台 **AJAX** 上传（`XMLHttpRequest + FormData`），文件和每图标题/描述按预览队列顺序提交，兼容无 `DataTransfer` 的浏览器；发布图集不整页刷新，失败原因明确提示。
- **质量 / 尺寸可调**：WebP 质量、缩略图最长边、普通图宽度上限、普通图质量、**全景图宽度**、**全景图质量** 均可配置（滑块/输入框），附「恢复默认最佳设置」（默认值集中定义）。
- **全景自动识别**：宽高比 ≈ **2:1（1.98~2.02）** 自动判定为 360 全景，**无需手动勾选**；上传/重建时全景用**独立宽度（默认 0=不裁剪）**与**独立质量（默认 92，比普通全图更高）**，保证 360 浏览清晰。
- **超大图内存自适应**：按像素数动态放宽 `memory_limit`（8K/8192×4096 全景也能正常转码，峰值约 260MB），避免 GD 编码 WebP 内存溢出。
- **分目录存储**：`usr/uploads/original/ full/ thumb/`，可保留原始文件。
- **权限自愈**：写入前校验目录可写，能修复时自动 `chmod`；仍不可写时给出具体目录与修复命令。
- **错误可见**：入库/重建失败原因（目录 / 写入 / 解码 / 缺原图）直接显示，不再笼统报错。
- **单图 60MP 上限保护**：超大图给出明确提示，避免内存溢出。
- **EXIF 读取**：相机、ISO、光圈、快门、焦距、闪光、拍摄时间（中文）、`lens`、GPS / 方向。
- **HEIC / HEIF / AVIF**：自动探测 `Imagick / ImageMagick / heif-convert`，失败自动回退，非标准路径可在后台指定。
- **批量维护**：重建缩略图/全图（AJAX 进度，**套用全景专属宽度/质量**，缺原图计失败）、清理孤儿文件、**重建尺寸字段**（为历史图集补齐宽高）、**清理非插件文章**。

### 首页与展示（前台体验）

- **无限瀑布流**：JS 把图片卡按响应式列数分配到弹性列、首行顶对齐；**滚动到底自动加载下一页**，使用保留筛选条件的游标，同时提供原生下一页链接。
- **顺序稳定**：缩略图按真实宽高 `aspect-ratio` 预占位，图片懒加载后不再导致列重排、顺序跳变；无限加载的新卡片同样生效。
- **懒加载**：原生 `loading="lazy"` + 滚动检测按需加载。
- **统一边距与圆角**：14px 间距、10px 圆角。
- **悬浮底栏**：居中圆角胶囊；点击左侧站点信息打开「关于」面板，右侧全屏按钮。
- **灯箱大图**：poptrox 单实例；PC / 移动端统一用**底部上一张 / 下一张按钮**；**渐进加载 blur-up**（缩略图垫底、原图解码后柔和淡入）；宽幅自动收缩为 EXIF 侧栏让位；**多图图集内切换**。
- **柔和非线性动效**：灯箱淡入淡出、EXIF 侧栏出现/消失、主图 blur-up 均采用柔和缓动（`easeInOutQuad` / `cubic-bezier(0.45,0,0.55,1)`），不生硬。
- **全景 360° 浏览**：灯箱内当前图若是全景，**自动用 Pannellum 渲染可拖拽旋转/滚轮缩放**；视窗比例**移动端 4:3、桌面端 16:9**；拖拽松手（含在视窗外松手）不会误关闭；非全景保持普通图片；切换/关闭自动销毁；Pannellum 本地内置、不依赖 CDN。
- **全景全屏 + 角标**：全景图灯箱右上角有**「全屏」按钮**，全屏后变**「退出全屏」**；全景卡片右上角带**「全景」角标**，一眼区分。
- **EXIF 侧栏**：主图外侧显示标题 / 描述 / 拍摄参数 / 地址，随图片联动。
- **EXIF 侧栏动效**：出现/消失为非线性缓动 + 轻微上浮，与灯箱开合风格一致。
- **关于面板**：标题固定「关于」、页脚 InfinityTime Theme 链接、打开遮罩调淡（不再像占满屏黑幕）。

### 后台配置（现代卡片 + 标签页，全部 AJAX）

- **标签页导航**：上传发布 / 已发布图集 / 站点信息 / 联系方式 / 转换设置 / 维护，长表单不再一屏滚到底。
- **上传并发布图集**：支持**拖拽上传**与多选，实时预览、逐张标题/描述、**拖拽排序**、**上传进度**；AJAX 发布，成功后图集列表局部刷新并清空表单。
- **已发布图集**：折叠展示（缩略图 lazy 加载）；展开可编辑图集信息、每图标题/描述/地址、**拖拽调整图片顺序**、逐张删除、删除整组（均 AJAX）。
- **站点信息 / 关于**：头像（**支持直接上传**，自动转 WebP、独立宽度、自动清理旧图）、站点名称、说明、关于介绍（保存前做 HTML 清洗）。
- **联系方式 / 联系我**：可视化选图标、增删/启停（AJAX）。
- **WebP 转换设置**：按 **通用保留原图 / 缩略图 / 普通图 / 全景图** 分组；宽度、**质量滑块**；转换工具状态；「恢复默认最佳设置」（AJAX）。
- **维护**：重建缩略图/全图、清理孤儿文件、重建尺寸字段、**清理非插件文章**；进度实时刷新，刷新页面后可继续未完成任务，并带并发锁。
- **安全加固**：所有写操作与维护任务仅接受带 CSRF token 的 POST、上传单文件大小/像素前置校验、「关于」HTML 危险标签/事件/协议清洗。

真实数据库测试仅在一次性测试库运行，例如：`TYPECHO_ROOT=/path/to/typecho php tests/typecho-integration.php Pdo_SQLite`。其他适配器为 `SQLite`、`Pdo_Mysql`、`Mysqli`、`Pdo_Pgsql`、`Pgsql`，连接参数使用 `IT_DB_HOST`、`IT_DB_PORT`、`IT_DB_NAME`、`IT_DB_USER`、`IT_DB_PASSWORD` 环境变量。测试会创建随机前缀的表并在结束时清理。

字段聚合同步使用主库保存点：失败保留完整旧字段，不提交或回滚调用方的其他事务。MySQL 的 `fields` 表必须使用 InnoDB；非事务引擎会在写入前明确拒绝，需要管理员先备份并自行迁移，本插件不会自动改动站点表引擎。

维护检查点有独立任务标识。未完成的同类任务继续原清单与进度，完成后再次开始会重新收集候选；迟到轮询不能覆盖新任务。磁盘写入失败会明确报错，重建字段失败计入失败数，可运行「重建尺寸字段」重试。首批已完成但响应丢失后，手动再次开始属于新任务，可能重复处理，但不会复用过期快照。

单图删除将图片行和聚合字段放在同一事务中，确认自行提交后才清理无引用实体；调用方外层事务尚未结束时保留文件，由提交后的安全孤儿清理回收。数据库与文件系统没有跨系统原子提交：提交后崩溃、连接结果未知或清理失败可能留下孤儿，优先避免丢失可恢复文件。历史 URL 的查询参数、编码和点目录会保守纳入引用保护。

上传中只更新当前照片卡片，服务器确认成功且返回图片标识后才释放本地文件资源，失败项保留重试。200 张隔离 DOM/XHR 样本的创建节点数从 1,124,203 降至 8,403，全部成功后的 ObjectURL 从 200 降至 0；这仅是测试样本的 DOM/资源数据，完整队列统计与持久化仍有遍历，不代表全部算法线性或线上耗时承诺。

主图与缩略图使用同目录暂存文件，全部编码并校验后再依次替换；编码失败不会提前覆盖旧图。两个文件的 rename 不能形成跨文件原子事务，发布中途磁盘失败仍可能保留不同代但各自完整的输出，可重建恢复。WebP 编码单边上限为 16383px，超限会明确拒绝，不暗中改变用户的全景尺寸设置。AVIF 读取失败先尝试已有 WebP，仍失败才显示重试。

孤儿引用扫描仅读六个路径列，不缓存旧引用；每批删除前仍在媒体锁内核验。可运行 `php tests/orphan-performance.php` 在隔离 SQLite 中对比返回量和查询中位数，测试不使用机器相关的耗时通过阈值。

维护与上传现在通过同一上传根目录内的文件锁互斥，媒体处理串行执行，逐图队列在忙时保留状态并提示重试，不会并发启动多张转换。孤儿清理只处理至少一小时前的文件，恢复任务时重新核验数据库引用与文件身份；旧版任务快照会安全跳过，重新启动清理即可。文件锁需要底层文件系统支持可靠的 `flock`（多节点部署需共用支持锁的上传卷）。

### 后端
- PHP ≥ 7.4（推荐 8.x）+ Typecho 1.3；`php-gd`（WebP/缩放）、`php-exif`、可选 `php-imagick` / ImageMagick / `heif-convert`。
- 存储：独立表 `typecho_infinitytime_images`（兼容 MySQL / SQLite / PostgreSQL），图集复用 Typecho `contents` + `fields`。
- 配置：插件 `options` + 主题 `pp_opt()`；默认值统一为插件常量。

### 前端
- 原生 HTML/CSS/JS + jQuery；瀑布流、无限滚动、灯箱均原生实现。
- 灯箱：poptrox 二次封装；**全景：Pannellum（本地内置 `assets/js/pannellum.js` + `assets/css/pannellum.css`）**。
- 同步：`MutationObserver` + 轻量轮询；图标本地 iconfont，不依赖 CDN。

## 安装

### 方式一：直接放入 Typecho
把仓库两份目录拷到 Typecho 站点：
```text
usr/themes/InfinityTime/     # 主题
usr/plugins/InfinityTime/    # 插件
```
或用 GitHub Release 里的 `infinitytime-theme.zip` / `infinitytime-plugin.zip`，解压后分别放入对应目录。

### 启用
1. 后台 **设置 → 插件**，启用 **InfinityTime**（自动建表、自检上传目录、注册菜单）。
2. 后台 **外观 → 主题**，启用 **InfinityTime**。
3. 进入 **InfinityTime** 菜单上传图片发布图集，回前台即可看到无限瀑布流图片墙。

### 环境要求
- PHP ≥ 7.4，启用 `php-gd`、`php-exif`。
- HEIC/AVIF：安装 `php-imagick + libheif`、`ImageMagick + libheif` 或 `libheif-examples`（`heif-convert`）；非标准路径在插件设置填。
- 上传限制：建议 `upload_max_filesize` / `post_max_size` ≥ 20M（8K 全景 JPG 常 15MB+）。
- 大图内存：自动放宽，约需 512M；服务器建议至少 1GB 内存。

## 使用体验

### 后台
1. **上传并发布图集** — 拖拽/多选上传、逐张标题/描述、拖拽排序、上传进度；AJAX 发布。
2. **已发布图集** — 展开编辑整组信息、每图信息、拖拽排序、删除图片/图集（均 AJAX）。
3. **站点信息 / 关于 / 联系方式** — 头像直传、名称、介绍（HTML 清洗）、联系方式（AJAX）。
4. **WebP 转换设置** — 分组配置：保留原图 / 缩略图 / 普通图 / 全景图（宽度 + 质量滑块）；「恢复默认最佳设置」。
5. **维护** — 重建缩略图/全图、清理孤儿文件、重建尺寸字段、**清理非插件文章**（先预览后删除），支持断点续跑与并发锁。

### 前台
- 首页无限瀑布流，滚到底自动加载更多；缩略图按需加载。
- 点击缩略图打开灯箱；**360 全景拖拽旋转/缩放**；普通图左右切换；EXIF 侧栏随图联动。
- 底部悬浮胶囊：左侧「关于」面板、右侧全屏。

## 常见问题
- **全景上传失败？** 之前是 GD 在 8192×4096 时内存不足，v1.6.0 已按像素动态放宽内存；确认后台「全景图宽度」为 0（不裁剪）或一个合理值。
- **全景不清晰？** 用「全景图宽度 = 0」+「全景图质量 ≥ 90」，然后重新上传或在维护里重建。
- **重建后没变化？** AJAX 完成后不刷新；同 URL 有浏览器缓存，强刷（Cmd+Shift+R）再看。
- **清理非插件文章？** 维护 → 清理非插件文章，会先列出数量/标题再确认删除（不可恢复）。
