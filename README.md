# InfinityTime · 无限时光

一款面向 [Typecho](https://typecho.org) 的**纯图片分享方案**。上传一张图，自动得到 **WebP 全图 + 缩略图**并读取 **EXIF**；前台是**无限瀑布流图片墙 + 灯箱**，灯箱侧栏展示拍摄参数；**360° 全景图在灯箱内直接可拖拽/缩放浏览**；后台可视化配置一切，且**所有操作均已 AJAX，不整页刷新**。

> 主题 `InfinityTime` 负责展示，插件 `InfinityTime` 负责处理。**只需安装这两部分，无需改动任何 Typecho 原生文件。**

> **v1.7.2** 重点：**修复无限瀑布流新图片未绑定灯箱**（翻页后安全重绑，点击不再直接跳原图）；**全景全屏时不响应“点击退出”**；`main.js` JSON 解析兜底、轮询与全景监听健壮性优化。**v1.7.1** 起已含：存储型 XSS 防护、后台 CSRF 同源校验、死代码清理；**v1.7.0** 起已含：全景灯箱「全屏/退出全屏」按钮、全景角标、首页不再缓存 + 资源 `?v=` 版本号；**v1.6.0** 起已含：全景 2:1 自动识别拖拽缩放、后台全 AJAX、无限瀑布流、清理非插件文章。

## 功能特性

### 图片处理（后端核心）

- **上传即转 WebP**：拦截 Typecho 上传钩子，自动生成全尺寸 WebP 与缩略图。
- **上传可靠**：后台 **AJAX** 上传（`fetch + FormData`，保持 `DataTransfer` 同步文件选区与每图标题/描述），发布图集不整页刷新，失败原因明确提示。
- **质量 / 尺寸可调**：WebP 质量、缩略图最长边、普通图宽度上限、普通图质量、**全景图宽度**、**全景图质量** 均可配置（滑块/输入框），附「恢复默认最佳设置」（默认值集中定义）。
- **全景自动识别**：宽高比 ≈ **2:1（1.98~2.02）** 自动判定为 360 全景，**无需手动勾选**；上传/重建时全景用**独立宽度（默认 0=不裁剪）**与**独立质量（默认 92，比普通全图更高）**，保证 360 浏览清晰。
- **超大图内存自适应**：按像素数动态放宽 `memory_limit`（8K/8192×4096 全景也能正常转码，峰值约 260MB），避免 GD 编码 WebP 内存溢出。
- **分目录存储**：`usr/uploads/original/ full/ thumb/`，可保留原始文件。
- **权限自愈**：写入前校验目录可写，能修复时自动 `chmod`；仍不可写时给出具体目录与修复命令。
- **错误可见**：入库/重建失败原因（目录 / 写入 / 解码 / 缺原图）直接显示，不再笼统报错。
- **单图 60MP 上限保护**：超大图给出明确提示，避免内存溢出。
- **EXIF 读取**：相机、ISO、光圈、快门、焦距、闪光、拍摄时间（中文）、`lens`、GPS / 方向。
- **HEIC / HEIF / AVIF**：自动探测 `Imagick / ImageMagick / heif-convert`，失败自动回退，非标准路径可在后台指定。
- **批量维护**：重建缩略图/全图（AJAX 进度，**套用全景专属宽度/质量**，缺原图计失败）、清理孤儿文件、**清理非插件文章**。

### 首页与展示（前台体验）

- **无限瀑布流**：JS 把图片卡按响应式列数分配到弹性列、首行顶对齐；**滚动到底自动加载下一页**（`index.php/page/N`），无分页页码。
- **懒加载**：原生 `loading="lazy"` + 滚动检测按需加载。
- **统一边距与圆角**：14px 间距、10px 圆角。
- **悬浮底栏**：居中圆角胶囊；点击左侧站点信息打开「关于」面板，右侧全屏按钮。
- **灯箱大图**：poptrox 单实例，上一张/下一张、移动端左右滑动；**渐进加载 blur-up**；宽幅自动收缩为 EXIF 侧栏让位；**多图图集内切换**。
- **全景 360° 浏览**：灯箱内当前图若是全景，**自动用 Pannellum 渲染可拖拽旋转/滚轮缩放**；拖拽松手（含在视窗外松手）不会误关闭；非全景保持普通图片；切换/关闭自动销毁；Pannellum 本地内置、不依赖 CDN。
- **全景全屏 + 角标**：全景图灯箱右上角有**「全屏」按钮**，全屏后变**「退出全屏」**；全景卡片右上角带**「全景」角标**，一眼区分。
- **EXIF 侧栏**：主图外侧显示标题 / 描述 / 拍摄参数 / 地址，随图片联动。
- **关于面板**：标题固定「关于」、页脚 InfinityTime Theme 链接、打开遮罩调淡（不再像占满屏黑幕）。

### 后台配置（管理体验，均 AJAX）

- **上传并发布图集**：标题、设备、地址、标签 + 多图上传；AJAX 发布，成功后图集列表局部刷新并清空表单。
- **已发布图集**：折叠展示；展开可编辑图集信息（AJAX）、每图标题/描述/地址（AJAX）、逐张删除（AJAX）、删除整组（AJAX）。
- **站点信息 / 关于**：头像（**支持直接上传**，自动转 WebP、独立宽度、自动清理旧图）、站点名称、说明、关于介绍（AJAX）。
- **联系方式 / 联系我**：可视化选图标、增删/启停（AJAX）。
- **WebP 转换设置**：按 **通用保留原图 / 缩略图 / 普通图 / 全景图** 分组；宽度、**质量滑块**；转换工具状态；「恢复默认最佳设置」。
- **维护**：重建缩略图/全图、清理孤儿文件、**清理非插件文章**（先预览数量并列出标题，确认后删除非本插件发布的 `type=post` 文章）。

## 技术栈

### 后端
- PHP ≥ 7.4（推荐 8.x）+ Typecho 1.3；`php-gd`（WebP/缩放）、`php-exif`、可选 `php-imagick` / ImageMagick / `heif-convert`。
- 存储：独立表 `typecho_infinitytime_images`（兼容 MySQL / SQLite / PostgreSQL），图集复用 Typecho `contents` + `fields`。
- 配置：插件 `options` + 主题 `pp_opt()`；默认值统一为插件常量。

### 前端
- 原生 HTML/CSS/JS + jQuery；瀑布流、无限滚动、灯箱均原生实现。
- 灯箱：poptrox 二次封装；**全景：Pannellum（本地内置 `assets/js/pannellum.js` + `assets/css/pannellum.css`）**。
- 同步：`MutationObserver` + 轻量轮询；图标本地 iconfont，不依赖 CDN。

## 安装

### 方式一：直接放入 Typecho
把仓库两份目录拷到 Typecho 站点：
```text
usr/themes/InfinityTime/     # 主题
usr/plugins/InfinityTime/    # 插件
```
或用 GitHub Release 里的 `infinitytime-theme.zip` / `infinitytime-plugin.zip`，解压后分别放入对应目录。

### 启用
1. 后台 **设置 → 插件**，启用 **InfinityTime**（自动建表、自检上传目录、注册菜单）。
2. 后台 **外观 → 主题**，启用 **InfinityTime**。
3. 进入 **InfinityTime** 菜单上传图片发布图集，回前台即可看到无限瀑布流图片墙。

### 环境要求
- PHP ≥ 7.4，启用 `php-gd`、`php-exif`。
- HEIC/AVIF：安装 `php-imagick + libheif`、`ImageMagick + libheif` 或 `libheif-examples`（`heif-convert`）；非标准路径在插件设置填。
- 上传限制：建议 `upload_max_filesize` / `post_max_size` ≥ 20M（8K 全景 JPG 常 15MB+）。
- 大图内存：自动放宽，约需 512M；服务器建议至少 1GB 内存。

## 使用体验

### 后台
1. **WebP 转换设置** — 分组配置：保留原图 / 缩略图 / 普通图 / 全景图（宽度 + 质量滑块）；「恢复默认最佳设置」。
2. **上传并发布图集** — 多选图、逐张标题/描述；AJAX 发布，成功后列表局部刷新。
3. **已发布图集** — 展开编辑整组信息、每图信息、删除图片/图集（均 AJAX）。
4. **站点信息 / 关于 / 联系方式** — 头像直传、名称、介绍、联系方式（AJAX）。
5. **维护** — 重建缩略图/全图、清理孤儿文件、**清理非插件文章**（先预览后删除）。

### 前台
- 首页无限瀑布流，滚到底自动加载更多；缩略图按需加载。
- 点击缩略图打开灯箱；**360 全景拖拽旋转/缩放**；普通图左右切换；EXIF 侧栏随图联动。
- 底部悬浮胶囊：左侧「关于」面板、右侧全屏。

## 常见问题
- **全景上传失败？** 之前是 GD 在 8192×4096 时内存不足，v1.6.0 已按像素动态放宽内存；确认后台「全景图宽度」为 0（不裁剪）或一个合理值。
- **全景不清晰？** 用「全景图宽度 = 0」+「全景图质量 ≥ 90」，然后重新上传或在维护里重建。
- **重建后没变化？** AJAX 完成后不刷新；同 URL 有浏览器缓存，强刷（Cmd+Shift+R）再看。
- **清理非插件文章？** 维护 → 清理非插件文章，会先列出数量/标题再确认删除（不可恢复）。
